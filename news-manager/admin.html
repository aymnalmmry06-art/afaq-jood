# AFAQ JOOD — Local News Manager هذه لوحة إدارة أخبار مستقلة تعمل محلياً من VS Code ولا تحتاج Backend أو Database. ## ماذا تفعل؟ - إنشاء الأخبار - تعديل الأخبار - حذف الأخبار - مسودات محلية - Featured News - English / العربية / 中文 - صورة رئيسية - مصدر رسمي - تصنيف، دولة، جهة تنظيمية، المنتجات المتأثرة، الأثر التنظيمي - توليد slug تلقائياً - نشر مباشر إلى GitHub - قراءة الأخبار المنشورة الحالية من `news.json` - تعديل الخبر الموجود مع الحفاظ على بياناته الحالية - حذف الخبر من `news.json` وحذف صورته إذا كانت ضمن `assets/news/` - رفع الصورة إلى `assets/news/` - Netlify يلتقط Commit من GitHub ويعيد النشر تلقائياً ## لا يوجد Backend المسار هو: Local News Manager → GitHub API → GitHub Commit → Netlify → Website الـ GitHub token لا يتم وضعه داخل ملفات الموقع ولا يتم رفعه إلى GitHub. يتم الاحتفاظ به في Session Storage للمتصفح فقط، ويُرسل مباشرة إلى api.github.com. ## التشغيل لا تفتح `admin.html` بالنقر المزدوج. شغّل مجلّد المشروع بواسطة VS Code Live Server. مثال: 1. افتح المجلد في VS Code. 2. ثبّت Live Server إذا لم يكن موجوداً. 3. اضغط يمين على `admin.html`. 4. اختر `Open with Live Server`. ## أول تشغيل افتح: GitHub Connection القيم الافتراضية: Owner: `aymnalmmry06-art` Repository: `Testing` Branch: `main` ثم أدخل Fine-grained Personal Access Token. يجب أن يكون الـ token محدوداً على Repository `Testing` فقط، مع: Repository permissions → Contents → Read and write ثم Test & Connect. ## ملاحظة مهمة هذه اللوحة لا تغيّر ملفات التصميم الموجودة في موقعك. عند نشر خبر، تضيف/تحدّث فقط: - `news.json` - `assets/news/.jpg` عند وجود صورة - `news//index.html` وعند الحذف تزيل الخبر من `news.json` وتحذف صورة الخبر إذا كانت محفوظة داخل `assets/news/`. لا يتم إنشاء صفحات HTML ثابتة للأخبار؛ الموقع الحالي يستخدم المسار الديناميكي `/news//` عبر Netlify. لكي يظهر الخبر في الموقع الحالي، يجب أن يكون موقعك يحتوي بالفعل على واجهة الأخبار المتوافقة التي تقرأ `news.json` وتستخدم `news.js` و`news-article.html`/التوجيه المناسب. الملف الذي تم بناء هذه اللوحة على أساسه يحتوي على بنية أخبار AFAQ JOOD المتوافقة مع: - `news.json` - `news.js` - `news.css` - `news-article.html` - `news.html` إذا كانت هذه الملفات موجودة في مستودع `Testing`، فاللوحة جاهزة للاستخدام مباشرة. ## الروابط كل خبر جديد يحصل على: `https://afaqjood.com/news//` مثال: `https://afaqjood.com/news/uae-tdra-type-approval-update/` يتم تثبيت الرابط بعد أول نشر؛ تغيير عنوان الخبر لاحقاً لا يغيّر slug الخبر الموجود. ## الأمان لا تستخدم GitHub token عادي بصلاحيات واسعة. استخدم Fine-grained token مخصصاً لمستودع `Testing` فقط. بعد الانتهاء، اضغط Clear local token. ## لماذا لا يوجد Netlify Token؟ لا تحتاج اللوحة إلى Netlify API. بمجرد أن تعمل Netlify Git Integration مع مستودع GitHub، أي Commit جديد على `main` يطلق Deploy تلقائياً. ## حدود هذا التصميم هذه ليست قاعدة بيانات. GitHub هو مخزن المحتوى، وGit history هو سجل التغييرات. لذلك يمكن العمل بدون خادم 24/7 وبدون MySQL/Firebase/Supabase. ## التحديثات في هذا الإصدار - الجهة التنظيمية/الوزارة تُعبأ تلقائياً بعد اختيار الدولة من القائمة. - المنتجات المتأثرة اختيارية، وإذا تُركت فارغة لا تظهر في الخبر. - اسم المصدر ورابط المصدر اختياريان، وإذا لم يوجد رابط مصدر فلا يظهر صندوق المصدر في الخبر. - حفظ الخبر أصبح يضعه في **أرشيف محلي** على جهازك. - من صفحة الأرشيف يوجد زر **نشر كل الأخبار المؤرشفة** لنشر جميع المسودات في Commit واحد إلى GitHub، ثم يقوم Netlify بالنشر تلقائياً. - كل خبر يحتفظ بـ `countryCode` واسم الدولة، ولذلك يظهر تلقائياً في قسم أخبار الدولة في موقع AFAQ JOOD عندما يكون قسم أخبار الدولة موجوداً في الموقع ويقرأ `news.json`.
