# AFAQ JOOD — Final QA / News & CMS Fixes — 14 September 2026

## Status
Production package prepared for GitHub + Netlify.

## News article routing fix
- Fixed the root cause of the “Read article” issue on `/news/<slug>/`.
- `news.js` now loads `/news.json` from the site root rather than a relative `news/news.json` path.
- `news-article.html` now uses root-absolute CSS, JS and asset paths so the Netlify pretty URL `/news/<slug>/` cannot resolve scripts/styles under `/news/`.
- Back-to-News and navigation links from an article use root-absolute paths.
- Netlify rewrite remains:
  `/news/* -> /news-article.html?slug=:splat` with status 200.

## News CMS synchronization
- Added the standalone News Manager under `/news-manager/`.
- `/admin.html` redirects to `/news-manager/admin.html`.
- The manager reads the existing `news.json` from the configured GitHub repository, so the four existing news items are editable/deletable rather than being disconnected seed content.
- Publishing writes to `news.json` and `assets/news/` only; no duplicate static HTML article pages are created.
- Editing an existing article preserves existing non-English translation fields instead of overwriting them with English-only data.
- Deleting an article removes it from `news.json` and removes its news image when the image is stored under `assets/news/`.
- Manager can re-sync manually and automatically every 60 seconds while connected.
- GitHub token remains in browser Session Storage and is not written into the repository.
