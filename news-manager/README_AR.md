# AFAQ JOOD — News Manager

هذه لوحة إدارة الأخبار المرتبطة مباشرة بمستودع موقع AFAQ JOOD.

## المبدأ

News Manager → GitHub (`Testing`) → Netlify → موقع AFAQ JOOD

عند الاتصال بالمستودع، تقوم اللوحة بقراءة `news.json` الحالي، لذلك تظهر الأخبار الموجودة بالفعل ويمكنك:

- تعديل الخبر الموجود.
- حذف الخبر من الموقع.
- إنشاء خبر جديد.
- حفظ مسودات محلية.
- نشر الأخبار إلى GitHub.
- رفع الصور إلى `assets/news/`.
- مزامنة الأخبار تلقائياً كل دقيقة أثناء بقاء جلسة GitHub متصلة.

**مهم:** عند تعديل خبر موجود، يتم الحفاظ على الحقول والترجمات الموجودة في `news.json` التي لا تعدلها اللوحة، ولا يتم إنشاء صفحات HTML ثابتة منفصلة للأخبار. موقع AFAQ JOOD يفتح الخبر عبر `/news/<slug>/` ويقرأ المحتوى من `news.json`.

## الاتصال

الإعداد الافتراضي:

- Owner: `aymnalmmry06-art`
- Repository: `Testing`
- Branch: `main`

أدخل Fine-grained GitHub Token بصلاحية:

`Contents: Read and write`

على مستودع `Testing` فقط.

المفتاح يحفظ في Session Storage للمتصفح فقط، ولا يوضع داخل ملفات الموقع.

## الصور

يمكن رفع صورة لكل خبر. يتم ضغط الصورة قبل رفعها إلى:

`assets/news/<country>/<slug>.jpg`

الأخبار الحالية في الموقع تحتوي على صور تحريرية جاهزة.

## لا توجد أسعار

هذه اللوحة والموقع العام لا يعرضان أسعار خدمات AFAQ JOOD أو رسوم الجهات التنظيمية أو أي جداول أسعار.

## الرابط داخل الموقع

يمكن فتح اللوحة من:

`/news-manager/admin.html`

والخبر العام من:

`/news/<slug>/`
