AFAQ JOOD V15 — Translation & Typography Revision

Languages currently implemented and audited: English, Arabic, Chinese.

Translation scope:
- Main one-page site sections
- Desktop and mobile navigation
- Buttons, labels, placeholders, footer, contact blocks
- Market directory and search results
- Interactive map popup labels
- Country detail pages, including facts, products, documentation, compliance, workflow, FAQ, source/data integrity and sidebar CTA
- Country names, regions, scopes and product labels in Arabic/Chinese
- Country regulatory values receive phrase-level localization while preserving official acronyms, model names and regulatory terminology.

Typography:
- The CSS now uses "29LT Bukra" as the primary site font with system fallbacks.
- The 29LT Bukra font is proprietary/licensed. No font file is bundled without a valid web license. If the font is installed on the user's computer, the site will use it automatically. For universal display on Netlify/other hosting, add a properly licensed webfont file from 29LT.
